# کهربا — فروشگاه آنلاین دخانیات (نسخهٔ آزمایشی)

سایت استاتیک (HTML/CSS/JS خالص) با تم تیرهٔ قهوه‌ای و برنجی.

## ویژگی‌ها
- دروازهٔ تأیید سن ۱۸+ هنگام ورود، هشدار سلامت ثابت بالای سایت و فوتر
- سبد خرید کشویی، نمای سریع محصول، فیلتر دسته و برند و قیمت، نوار دسته‌بندی ثابت
- تسویه‌حساب با احراز سن: اعتبارسنجی کد ملی (الگوریتم رسمی) و تاریخ تولد شمسی (زیر ۱۸ سال رد می‌شود)
- سقف ۱۰ عدد از هر کالا در هر سفارش، سه روش ارسال با تاریخ تحویل، کد تخفیف `KAHRBA10` و `WELCOME5`
- درگاه پرداخت آزمایشی (کارت منتهی به 0000 یا انصراف = ناموفق)، پیگیری سفارش

## انتشار روی GitHub Pages
فایل‌ها را در یک مخزن آپلود کنید ← Settings ← Pages ← شاخهٔ main، پوشهٔ root.

## قبل از انتشار واقعی
- فروش آنلاین دخانیات نیاز به مجوز و رعایت قوانین کشور شماست؛ پیش از راه‌اندازی بررسی حقوقی کنید.
- تأیید سن این پروژه فقط سمت مرورگر است و جایگزین بررسی سمت سرور نیست.
- نام محصولات و برندها نمونه‌اند. تلفن و نشانی را در `SITE` (ابتدای `app.js`) و قیمت‌ها را در `products.js` تغییر دهید.
- عکس واقعی: `images/p1.jpg` تا `p12.jpg`.
